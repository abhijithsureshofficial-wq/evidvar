# Data Dictionary

This document describes the key datasets generated and used in the EvidVar pipeline. All files are stored in compressed CSV format (`.csv.gz`) unless noted otherwise.

## 1. Raw Inputs (Not Committed)

### `data/raw/clinvar_variant_summary.txt.gz`
*   **Source:** NCBI FTP Server.
*   **Description:** The full ClinVar variant summary tab-delimited file.
*   **Size:** ~435 MB.
*   **Key Columns Used:**
    *   `VariationID`: Unique identifier for the variant record.
    *   `GeneSymbol`: Gene name (filtered for BRCA1/BRCA2).
    *   `ClinicalSignificance`: Curated classification (Pathogenic, Benign, VUS, etc.).
    *   `ReviewStatus`: Level of evidence supporting the classification.
    *   `RS# (dbSNP)`: dbSNP cluster ID.
    *   `Name`: HGVS nomenclature string (used for literature matching).

## 2. Intermediate Datasets

### `data/interim/brca_with_rsid.csv.gz`
*   **Generated By:** Cell 2 (Setup & Extraction).
*   **Description:** Subset of ClinVar containing only BRCA1/BRCA2 variants with valid rsIDs.
*   **Columns:** Same as raw input, plus `CleanRSID` (normalized lowercase rsID).

### `data/interim/pubmed_abstracts.csv.gz`
*   **Generated By:** Cell 7 (PubMed Retrieval).
*   **Description:** Abstracts fetched from PubMed matching BRCA1/2 keywords.
*   **Rows:** ~4,645 records.
*   **Columns:**
    *   `PMID`: PubMed Identifier.
    *   `Title`: Article title.
    *   `Abstract`: Full abstract text.

### `data/interim/ensembl_cache.json`
*   **Generated By:** Cell 4 (Ensembl Annotation).
*   **Description:** JSON cache storing raw API responses from Ensembl VEP to allow resumable annotation.
*   **Structure:** Map of `rsID` -> `VEP Response Object`.

## 3. Processed Datasets

### `data/processed/clinvar_brca_annotated_final.csv.gz`
*   **Generated By:** Cell 4 (Ensembl Annotation).
*   **Description:** The master structured dataset combining ClinVar labels with Ensembl functional annotations.
*   **Rows:** ~16,355 high-confidence labeled variants + VUS pool.
*   **Key Columns:**
    *   `VariationID`, `CleanRSID`, `GeneSymbol`.
    *   `label`: Binary target (1=Pathogenic/Likely Pathogenic, 0=Benign/Likely Benign, NaN=VUS/Conflict).
    *   `ClinicalSignificance`, `ReviewStatus`: Original ClinVar strings.
    *   `Consequence`: Semicolon-separated consequence terms (e.g., `missense_variant;splice_region_variant`).
    *   `SIFT`: SIFT score (float, NaN if not missense).
    *   `PolyPhen`: PolyPhen-2 HumDiv score (float, NaN if not missense).
    *   `AF`: Average allele frequency across populations (float, NaN if unavailable).

### `data/processed/evidence_sentences.csv.gz`
*   **Generated By:** Cell 8 (Strict HGVS Mining).
*   **Description:** Sentences extracted from PubMed abstracts that contain specific HGVS tokens matching known variants.
*   **Rows:** ~912 sentences.
*   **Columns:**
    *   `VariationID`: Linked ClinVar ID.
    *   `HGVS_Token`: The specific string matched (e.g., `c.68_69delAG`).
    *   `PMID`: Source paper ID.
    *   `Sentence`: The isolated sentence text.

### `data/processed/evidence_clean_all.csv.gz` / `_labeled.csv.gz` / `_uncertainty.csv.gz`
*   **Generated By:** Cell 9 (Evidence Cleaning).
*   **Description:** Filtered version of `evidence_sentences.csv.gz`. Removes vague tokens (e.g., bare positions like `c.631`) and duplicates.
*   **New Columns:**
    *   `variants_in_sentence`: Count of distinct variants mentioned in the same sentence (used for weighting).
    *   `evidence_types`: Rule-based tags (e.g., `functional_assay`, `segregation`, `population_frequency`).

### `data/processed/evidence_nlp_polarity.csv.gz`
*   **Generated By:** Cell 10b (Zero-Shot NLP).
*   **Description:** The core benchmark dataset. Each sentence is scored for pathogenic/benign support.
*   **Rows:** ~912.
*   **Columns:**
    *   All columns from `evidence_clean_all.csv.gz`.
    *   `path_score`: Probability of "supports pathogenic" hypothesis (0-1).
    *   `ben_score`: Probability of "supports benign" hypothesis (0-1).
    *   `polarity`: Derived class (`supports_pathogenic`, `supports_benign`, `ambiguous`, `neutral`).
    *   `confidence`: Max(path_score, ben_score).
    *   `conflict_score`: Measure of contradictory signals (high when both scores are significant).
    *   `circular`: Boolean flag indicating if the sentence merely restates database classifications (e.g., "According to ClinVar...").

### `data/processed/variant_features_supervised.csv.gz`
*   **Generated By:** Cell 11 (Aggregation).
*   **Description:** Final feature matrix for modeling. Merges structured features with aggregated text evidence.
*   **Rows:** 16,355 (Labeled Universe).
*   **Text Aggregation Columns:**
    *   `text_path`: Sum of weighted pathogenic scores.
    *   `text_ben`: Sum of weighted benign scores.
    *   `text_n`: Count of decided, non-circular sentences.
    *   `text_conflict`: Max conflict score among sentences.
    *   `text_mean_conf`: Mean confidence of sentences.
    *   `text_has`: Binary indicator (1 if `text_n` > 0).

## 4. Model Artifacts

### `results/models/fusion_config_8D.json`
*   **Description:** Configuration used for the final Bayesian fusion.
*   **Keys:**
    *   `alpha`: Selected weight for text evidence (default: 4.0).
    *   `af_threshold`: Threshold for ACMG frequency gate (default: 0.001).
    *   `clip`: Maximum absolute value for text log-ratio (default: 3.0).

### `results/models/structural_model_8D.pkl`
*   **Description:** Serialized `HistGradientBoostingClassifier` trained on structured features only. Used as the prior in the fusion step.
